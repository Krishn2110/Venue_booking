# 📘 EventFlow – Smart Event Booking System

A modern, responsive event booking platform that connects customers with event organizers and venues. Built using **React.js** and **Tailwind CSS**, EventFlow offers seamless event discovery, booking, and management.

---

## 🚀 Features

### **For Customers**
- 🔍 Browse curated events across multiple categories  
- 🧠 Smart search (location, date, category)  
- 🎫 Easy and secure booking  
- 🤖 AI-powered personalized recommendations  

### **For Vendors**
- 🏢 Create and manage events easily  
- 📣 Reach thousands of customers  
- 📊 Real-time analytics dashboard  
- 💼 Full booking and payment management  

### **Platform Features**
- 📱 Fully responsive UI  
- 🔐 Secure payments  
- 🔔 Real-time notifications  
- 🌍 Multi-language support  
- 🔗 Social integration  

---

## 🛠 Tech Stack

- **React.js 18+**  
- **Tailwind CSS**  
- **React Router DOM**  
- **Heroicons / Custom SVGs**  
- **Poppins Font**  
- Build Tool: **Vite / Create React App**
